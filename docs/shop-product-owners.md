# 店铺按产品分配运营负责人

独立页面 `/settings/product-owners`，从首页侧栏、人员页、店铺设置进入；店铺表格提供带来源类型和店铺 ID 的直达链接。

同一店铺按具体规格指定不同运营人员，支持搜索公司名称、公司编码及原 SKU，逐项或批量配置、移除配置。候选人员限店铺小组内的在职人员。页面预览采用“产品单独负责人优先，否则沿用店铺默认负责人，否则未分配”，同一店铺、同一产品只允许一位负责人，避免重复归属。

产品列表来自当前 Base 快照的产品中心规格节点，不按名称猜测型号/上架关系。绑定使用显式 Base 目录/产品身份（base_product_key），没有来源身份的公司产品使用公司编码；不使用易随导入变化的节点数字 ID。不同店铺对同一产品可以配置不同人员。失效来源和产品保留原配置，可移除，不能新增或改派。

规则与店铺、小组、人员保存在同一 D1 业务配置及版本中。未传 product_owners 的旧客户端请求保留原规则。人员停用/调组会预览并清理不匹配的产品规则；店铺换组在草稿中清理旧组规则，和默认归属一起原子保存。历史订单不受影响。

本阶段只保存责任配置和展示默认负责人解析，不回写 Base，也不追溯重算已有订单。后续接入新订单归属时，需按订单商品明细保存归属快照；订单明确指定负责人优先于产品规则，正式扣减和归属结算仍按已确认口径实施。

验证：`node scripts/check-product-owners.mjs` 覆盖 SKU/店铺隔离、重复规则、同组校验、稳定产品身份、旧客户端兼容和版本冲突。浏览器覆盖单 SKU、默认回退、批量、跨浏览器保存、人员停用和店铺换组清理，以及移动端。
