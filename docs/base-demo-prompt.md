# Base 演示数据搭建提示词

以下内容可直接交给负责搭建 Base 测试环境的人或工具。本提示词不授权对当前生产账号执行写入；先选定独立测试账号或隔离的演示目录。

```text
请为“多平台销售与多仓库存中台”搭建可核对、可复现的 Base 演示数据。

一、边界
1. 使用独立测试账号或隔离目录，所有对象带 DEMO-MP 标识；不覆盖业务数据。
2. 不连接真实平台库存推送，不发送客户通知，不触发发货。
3. 核对 Base 实际字段与导入方式，不虚构平台、仓库、订单日期或海外仓 SKU 字段。
4. Base 无法维护的公司多层级、团队、人员、编码映射和份额，交付配套 CSV/XLSX，不伪装为原生功能。
5. 客户资料使用虚构信息，文件中不得包含 API 密钥。

二、公司产品及来源编码
建立 C51 父体，其下蓝色、黑色，每种颜色分别有 128G、512G 具体规格。
另建 C61 父体及至少两个具体规格。颜色可作为中间层，具体规格必须有唯一公司 SKU。
例如：DEMO-MP-C51 → DEMO-MP-C51-BL → DEMO-MP-C51-BL-512。
公司层级配套表至少包含：稳定编号、名称、上级编号、汇总/具体规格类型、颜色、容量/配置。
Base 父子关系按实际支持方式建立，多层公司树单独交付。
每个规格准备不同平台、店铺和仓库编码，并交付来源范围＋原编码＋公司 SKU 映射。
包含同规格多历史编码、同名不同规格、不同目录出现相同原编码。
父体不额外登记子体同一批实物或重复销量。

三、平台、店铺和团队
目标为 Amazon、eBay、TikTok，每平台两个店铺。
仅创建 Base 实际支持的测试来源；不能建立对应平台类型时使用明确标记的替代测试来源，提供目标平台映射，不连接真实交易账号。
配套建立一组、二组、三组，每组两名虚构员工。
交付店铺默认责任、SKU 专用责任，包含生效/结束日期。
包含一人多店、同店不同 SKU 归不同团队、同规格跨平台销售、未分配归属、人员调组前后历史。

四、订单
以搭建当天为基准，最近 30 个自然日至少 60 笔，覆盖最近 3/7/14 天和每日走势。
包含一单两台、同单多个 SKU 分归不同团队、已确认和未确认、取消、退款、退货、缺失映射、缺失负责人、时区午夜附近订单。
包含销售一组向库存二组借货的情形，借货记录与正常销售分开，不增加销量。
日期使用真实来源字段；不能设置原平台日期时交付平台订单日期配套表，不以确认、发货或导入日期冒充。
退货、虚拟记账及需排除的单据单独标识。
订单配套表保留订单 ID、明细标识、来源平台店铺、原 SKU、数量、日期、状态、确认标志、销售归属及库存来源说明。

五、仓库与库存
建立波兰仓、德国仓测试来源，保留实际 Base ID、目录、账号（如有）、仓库、来源编码、数量、获取时间。
同一公司规格 C51-蓝色-512G 必须包括两个独立实物仓场景：
A. 波兰仓三个来源编码：A 30 台归一组、B 30 台归二组、C 40 台归三组，仓库合计 100。
B. 德国仓一个来源编码 100 台，中台配套份额为一组 30、二组 30、三组 40。
两仓合计为 200 台；任何小组份额不得与对应来源实物再次相加。
同组同规格增加历史来源编码样例，保留明细用于归并核对。
另准备未分配、库存变化后份额不一致、待检退货、再次可售、报废、运输在途、虚拟库存样例。
Base 不支持的状态用配套表，不把供应商待入库直接当作运输在途，不把虚拟库存并入实物。

六、渠道分配
一组 30 台示例：Amazon 独占 20、eBay 独占 10。
另设由 Amazon/eBay 共享的池，池数量只计一次，不各复制一份。
小组份额未分完时保留未分配；渠道未分完时保留组内未分配。
交付独占与共享分配表；此数据不推送真实平台可售库存。

七、交付和验收
交付对象及 Base 实际 ID 清单、产品树、编码映射、组织人员、责任规则、订单明细及历史归属、库存来源、份额、渠道分配、字段对应、失败清单。
交付按日/平台/店铺/规格/小组/人员的预期销量及库存核对表。
提供“全部来源数量”和“明确状态筛选后的试算数量”两套结果。
取消/退款/退货最终扣减规则尚未确认，不自行认定为正式净销量。
记录基准日期、时区、状态 ID、试算规则，确保重复核对可复现。
各父体销量等于下级合计，公司库存与来源明细一致，份额不重复计数。
```

## 本地对应演示

仓库附带 `scripts/seed-business-demo.py`，只创建新的本地演示数据库，不调用 Base。它提供产品树、三平台六店、三组六人、60 笔订单和两个库存归属场景，供功能联调，不代表上述 Base 账号搭建已完成。其余边界情形由自动测试覆盖，Base 侧完整演示仍需按提示词准备。

```bash
.venv/bin/python scripts/seed-business-demo.py --db data/demo-business.sqlite3
DATA_PLATFORM_DB="$PWD/data/demo-business.sqlite3" .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

脚本拒绝覆盖任何已有数据库，输出同名 `.expected.json` 核对结果。演示数据库不要运行真实 Base worker，防止来源数据混入。要验证真实接入，使用独立 Base 测试账号配置与另一数据库。
