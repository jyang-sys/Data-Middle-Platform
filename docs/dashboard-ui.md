# 销售首页组件与在线演示

首页按“筛选 → 核心指标 → 趋势与平台贡献 → 产品与团队排名 → 明细分析”组织。保留深蓝侧栏，统一卡片、间距、字体和交互状态，不展示大段开发说明。

- 常用筛选：日期、平台、店铺、小组、公司产品；其余条件折叠，支持近 3/7/14/30 天。
- 指标卡：商品件数、去重订单数、动销规格数、活跃店铺数，辅助数值来自当前筛选，不编造环比、销售额或目标。
- 趋势：按日件数与平台切换，包含零销量日、峰值、键盘/悬停数值。
- 平台贡献、畅销产品及团队排名支持进一步查看；产品明细弹窗可跳转库存。
- 分析标签页收纳平台店铺、产品层级、小组人员、订单、月度每日报表，避免连续堆叠全部表格。
- 产品中心使用可搜索、可折叠的层级树及规格详情，关联本期销量和已确认库存。
- 库存中心补充指标卡，未知实物显示“待确认”，与已确认的零库存区分。

服务页面继续调用相同的后端统计和权限接口。只读快照额外捕获最近 30 天已获授权的可计入明细（含确认标志、状态 ID，不含客户资料），`snapshot-reports.js` 在其范围内计算日期、平台、店铺、小组、人员、产品及状态筛选。时区、日期口径和规则试算保持捕获时的值；切换需要运行中的服务。演示日期以捕获日期为基准，超出已捕获范围会明确提示，不伪装成零销量。

在线演示支持展开、明细、库存联动及 CSV；后台写入和真实同步不在静态 Site 中执行。`scripts/build-site-demo.py` 只接受明确标记的合成数据，不更改 Site 身份或访问范围。

验证：67 项自动测试通过，其中新增用 Node 对浏览器计算与后端结果逐项核对的测试，覆盖 12 类筛选、层级、订单去重、未映射及分页。浏览器验证四种快捷日期、平台筛选、高级条件、趋势/团队切换、商品弹窗、CSV、层级明细、产品搜索、库存联动及手机无横向溢出。
