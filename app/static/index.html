    连接你的 BaseLinker

    1. 在 BaseLinker 账户的 API 设置中取得 API 令牌。请妥善保管，不要发到聊天或提交到 Git。
    2. 在云环境设置中填写密钥 BASELINKER_API_TOKEN，允许访问 api.baselinker.com，保存并应用配置。
    3. 返回这里选择时间范围，点击“同步订单”。令牌只在服务端使用。
